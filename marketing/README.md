# ทีมการตลาด EVROUTE (Claude)

ทีมนี้คือผู้ช่วยเฉพาะทางของ Claude Code (กำหนดไว้ใน `.claude/agents/`) เปิด Claude Code ที่โปรเจกต์นี้ แล้วสั่งงานเป็นภาษาไทยได้เลย Claude ตัวหลักจะแบ่งงานให้คนในทีม

| ใคร | ทำอะไร |
|---|---|
| **marketing-lead** หัวหน้าทีม | วางแผนแคมเปญ ปฏิทินโพสต์ เลือกช่องทาง ตั้งเป้า เขียนบรีฟ สรุปผลจากหลังบ้าน |
| **route-researcher** ทีมข้อมูลเส้นทาง | วางแผนทริปจริงบน evroute.info เอาตัวเลขจริงมาให้ทีม |
| **content-writer** นักเขียน | โพสต์ Facebook / IG / LINE / Pantip / บทความ / ข้อความตอบคอมเมนต์ |
| **video-scripter** ทีมคลิป | สคริปต์ TikTok / Reels / Shorts พร้อมลำดับภาพที่ต้องถ่าย |
| **visual-designer** ทีมภาพ | ภาพโพสต์ สตอรี่ ภาพแชร์ลิงก์ จากตัวเลขจริง เป็นไฟล์ PNG |
| **fact-checker** ด่านตรวจ | ตรวจทุกชิ้นก่อนโพสต์ ตัวเลข คำพูดเกินจริง ลิงก์ ภาษา |

## สั่งงานอย่างไร

ตัวอย่างคำสั่ง:
- "ให้ทีมการตลาดทำแคมเปญหยุดยาว 5–7 ธ.ค. ทริปหน้าหนาว เหนือกับอีสาน"
- "ให้ route-researcher วางแผนกรุงเทพฯ → เขาใหญ่ ด้วย BYD Atto 3 แบต 90% แล้วให้ทีมทำโพสต์กับคลิป"
- "ให้ fact-checker ตรวจโพสต์ในแคมเปญล่าสุด"
- "สรุปผลแคมเปญจากตัวเลขหลังบ้านนี้ (แนบภาพหน้าจอหลังบ้าน)"

ลำดับงานปกติ:
1. **marketing-lead** วางแผน → `plan.md`
2. **route-researcher** วางแผนเส้นทางจริง → `routes.md`
3. **content-writer · video-scripter · visual-designer** ทำพร้อมกัน → `posts.md` · `scripts.md` · `images/`
4. **fact-checker** ตรวจ → `check.md`
5. **เจ้าของ** อ่าน แก้ แล้วโพสต์เอง (ทีมโพสต์ลง Facebook / TikTok / LINE แทนไม่ได้ และไม่ได้จ่ายค่าโฆษณา)

## ไฟล์อยู่ที่ไหน

- `marketing/facts.md` ข้อเท็จจริงที่ทุกคนใช้ **แก้ที่นี่ที่เดียวเมื่อแอปเปลี่ยน** (เช่น Longdo ตอบอนุญาตแล้ว เปิดตัวแล้ว)
- `docs/marketing.md` สโลแกน กติกาก่อนโพสต์ โพสต์ตัวอย่าง แผนโฆษณา
- `marketing/<วันที่>-<แคมเปญ>/` งานของแต่ละแคมเปญ

โฟลเดอร์ `marketing/` และ `docs/` เป็นของภายใน เว็บ evroute.info ไม่เปิดให้คนนอกดู
