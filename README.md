# วางแผนชาร์จ EV ทั่วไทย

เว็บวางแผนเดินทางด้วยรถยนต์ไฟฟ้าในประเทศไทย เลือกรุ่นรถ ใส่แบตที่เหลือ ต้นทางและปลายทาง แล้วระบบจะบอกว่าควรแวะชาร์จที่สถานีไหนบ้างตลอดทาง เพื่อไม่ให้แบตหมดกลางทาง

## ฟีเจอร์

- **เลือกยี่ห้อ/รุ่นรถ** (BYD, MG, GWM ORA, Tesla, NETA, AION, Deepal, ZEEKR, XPENG, Volvo, Hyundai, Kia, Toyota, BMW, Mercedes-Benz, Nissan, VinFast, Wuling และ "กำหนดเอง") ระบบมีค่าความจุแบต อัตรากินไฟ กำลังชาร์จ DC สูงสุด และชนิดหัวของแต่ละรุ่น ผู้ใช้ปรับเองได้ในเมนู "ปรับค่ารถ" (รวมถึง % ที่เผื่อไว้สำหรับแอร์ สัมภาระ ฝน)
- **แบตตอนออกเดินทาง** ใส่เป็น % หรือระยะวิ่งที่เหลือ (กม.), ตั้ง **"แวะชาร์จเมื่อแบตเหลือ"** (10–40%) และ **"ชาร์จถึง"** (60–100%)
- **ต้นทาง/ปลายทาง** พิมพ์ชื่อสถานที่ ใช้ตำแหน่งของฉัน หรือแตะบนแผนที่
- **แผนการชาร์จหลายจุด** ตามลำดับ กม. บนเส้นทาง: ชื่อสถานี ผู้ให้บริการ หัวชาร์จ/kW แบตตอนถึง → ชาร์จถึงกี่ % เวลาชาร์จโดยประมาณ และ kWh ที่เติม
- **ปรับแผนเองได้**: "เปลี่ยนสถานี" (เลือกสถานีอื่นในช่วงเดียวกัน), "ไม่แวะที่นี่" หรือแตะสถานีบนแผนที่แล้วกด "แวะชาร์จที่นี่" ระบบคำนวณช่วงที่เหลือให้ใหม่
- **เปิดเส้นทางทั้งหมดใน Google Maps** โดยใส่จุดชาร์จเป็นจุดแวะ (waypoints) และลิงก์นำทางทีละช่วง (เพราะแอป Google Maps บนมือถือบางเครื่องรับจุดแวะได้ไม่เกิน 3 จุด)
- **ปุ่ม "จองผ่านแอป / เปิดแอป"** ของผู้ให้บริการแต่ละสถานี (Android → Play Store, iPhone → App Store, คอมพิวเตอร์ → เว็บไซต์) ลิงก์ตรงไปหน้าจองของสถานีนั้นยังทำไม่ได้ เพราะผู้ให้บริการไม่ได้เปิดลิงก์แบบนั้น
- ลิงก์แผนแชร์ได้ (ทุกค่าอยู่ใน URL), รองรับมือถือ, ภาษาไทย, สลับโหมดสว่าง/มืด

## วิธีคำนวณ

1. ขอเส้นทาง A → B จาก Valhalla พร้อมเวลาและระยะของแต่ละช่วงถนน
2. คิดพลังงานต่อ กม. จากค่ากินไฟของรถ × ตัวคูณตามความเร็วของช่วงนั้น (50 กม./ชม. ≈ 0.9×, 80 ≈ 1.0×, 100 ≈ 1.12×, 120 ≈ 1.3×) + % ที่เผื่อไว้
3. เลือกสถานีชาร์จ DC ที่ใช้กับหัวของรถได้ ห่างจากเส้นทางไม่เกิน 5 กม. (คิดระยะอ้อมเข้า-ออก)
4. หาชุดจุดแวะที่ใช้ **เวลารวมน้อยที่สุด** (ขับ + อ้อม + ชาร์จ + 5 นาทีต่อจุดสำหรับจอด/เสียบสาย) ด้วย dynamic programming โดยแบตไม่ต่ำกว่าค่าที่ตั้ง และแต่ละจุดชาร์จเท่าที่ช่วงถัดไปต้องใช้ (+2%) ไม่เกินค่า "ชาร์จถึง"
5. เวลาชาร์จใช้กำลัง = min(กำลังสถานี, กำลังรถ) ลดลงเมื่อแบตเกิน 50% และลดมากหลัง 80%
6. ขอเส้นทางจริงผ่านจุดแวะทั้งหมดอีกครั้ง แล้วคำนวณแบตแต่ละช่วงใหม่จากเส้นทางนั้น

ตัวเลขทั้งหมดเป็นค่าประมาณ ระยะวิ่งจริงขึ้นกับการขับ อากาศ ทางขึ้นเขา และสภาพแบต

## แหล่งข้อมูลสถานีชาร์จ

| แหล่ง | จำนวน | ข้อมูล | ไฟล์ / วิธีดึง |
| --- | --- | --- | --- |
| PEA VOLTA (การไฟฟ้าส่วนภูมิภาค) | 407 สถานี DC | ชื่อ ที่อยู่ เวลาเปิด พิกัด กำลัง (25/50/120/300/360 kW) **ไม่ระบุชนิดหัว** (ระบบถือเป็น CCS2 และแสดงว่า "ยังไม่ยืนยัน") | `data/stations.json` จาก Google My Map สาธารณะที่ลิงก์จาก [หน้าสถานีของ PEA VOLTA](https://peavoltaev.pea.co.th/pea-volta-charging-stations/) |

| OpenStreetMap | ~230 | หัวชาร์จ/kW เฉพาะบางสถานี | Overpass วันละครั้ง (`server.mjs`) ถ้าไม่ตอบใช้ `data/osm-th.json` (snapshot) |

- สถานีที่อยู่ห่างกันไม่เกิน 120 ม. ถือเป็นที่เดียวกัน (ลำดับความสำคัญ: รายการที่รวบรวม > Open Charge Map > OSM)
- สถานีของเครือข่าย DC ที่รู้จัก (PTT EV Station PluZ, EleXA, EA Anywhere ฯลฯ) ที่ไม่มีข้อมูลหัวชาร์จ จะถือเป็น CCS2 50 kW และแสดงว่า "ยังไม่ยืนยัน"
- Tesla Supercharger ใช้ได้เฉพาะรถ Tesla
- **ยังขาด**: EA Anywhere (เงื่อนไขการใช้งานห้ามดึงข้อมูล), PTT EV Station PluZ, EleXA, MEA EV, Tesla, Bangchak, Shell, MG, Sharge ไม่มีรายการสถานีสาธารณะ ข้อมูลจากเครือข่ายเหล่านี้มีเฉพาะที่อยู่ใน OSM
- ไม่มีสถานะว่าง/ไม่ว่างแบบ real-time (ไม่มีแหล่งฟรี) ผู้ใช้ตรวจในแอปผู้ให้บริการ

### เพิ่ม/แก้สถานีเอง

แก้ `data/stations.json` (server อ่านใหม่ทุกครั้งที่รีเฟรชข้อมูล) รูปแบบ:

```json
{ "name": "ชื่อสถานี", "operator": "PEA VOLTA", "lat": 14.97, "lng": 102.08,
  "province": "นครราชสีมา", "address": "...", "hours": "24 ชม.",
  "connectors": [{ "type": "CCS2", "kw": 120, "count": 2 }, { "type": "Type2", "kw": 22, "count": 1 }],
  "source": "https://..." }
```

`type`: `CCS2`, `CHAdeMO`, `GB/T`, `Type2`, `Tesla` หรือ `DC` (ไม่รู้ชนิดหัว) · ชื่อผู้ให้บริการที่ตรงกับ `data/operators.json` จะมีปุ่มเปิดแอป

### เพิ่ม/แก้รุ่นรถ

แก้ `assets/js/cars.js`: `kwh` = แบตที่ใช้ได้, `use` = กินไฟเฉลี่ย kWh/100 กม., `dc` = ชาร์จ DC สูงสุด kW, `plugs` = หัว DC ของรถ ค่าที่ใส่ไว้เป็นค่าประมาณจากสเปกผู้ผลิตและผู้ใช้จริง

## บริการอื่นที่ใช้

| บริการ | ใช้ทำ | เรียกผ่าน |
| --- | --- | --- |
| [Valhalla](https://valhalla1.openstreetmap.de) (FOSSGIS) | คำนวณเส้นทาง | `POST /api/route` |
| [Photon](https://photon.komoot.io) (Komoot) | ค้นหาสถานที่ | `/api/geocode?q=` |
| Overpass / Open Charge Map | สถานีชาร์จ | `/api/stations` (cache 24 ชม.) |

Valhalla และ Photon เป็นเซิร์ฟเวอร์สาธารณะสำหรับการใช้งานปริมาณน้อย ถ้ามีผู้ใช้มาก ควรตั้งเองหรือใช้บริการแบบเสียเงิน (แก้ URL ที่ `server.mjs` และ `assets/js/app.js`)

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
npm start            # หรือ node server.mjs → http://localhost:8080 (เปลี่ยนพอร์ตด้วย PORT=3000)
npm test             # ทดสอบตัววางแผน (node:test)
OCM_KEY=xxxx npm start   # เปิดใช้ข้อมูล Open Charge Map (สมัคร key ฟรีที่ openchargemap.org)
```

## Deploy บน Render

1. New + → **Web Service** → เลือก repo `medtrackq/evroute`
2. Runtime: **Node** · Build Command: `npm install` · Start Command: `npm start` · Instance: **Free** · Region: Singapore
3. (ไม่บังคับ) Environment → เพิ่ม `OCM_KEY`
4. กด Create แล้วรอจนขึ้น "Deploy live"

Render แบบฟรีจะหลับเมื่อไม่มีคนใช้ ครั้งแรกที่เปิดอาจรอ ~30 วินาที

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บ |
| `assets/js/app.js` | ฟอร์ม ค้นหาสถานที่ แผนที่ แสดงผล ลิงก์ Google Maps/แอป |
| `assets/js/plan.js` | ตัววางแผน: พลังงานตามความเร็ว เลือกสถานีใกล้เส้นทาง หาจุดแวะที่ใช้เวลาน้อยที่สุด เวลาชาร์จ |
| `assets/js/cars.js` | ข้อมูลรุ่นรถ |
| `assets/css/style.css` | สไตล์ (light/dark) |
| `lib/stations.mjs` | แปลงข้อมูล OSM / Open Charge Map / รายการที่รวบรวม เป็นรูปแบบเดียวกัน และรวมสถานีซ้ำ |

| `data/stations.json` | รายการสถานี DC ที่รวบรวมจากหน้าเว็บสาธารณะของผู้ให้บริการ |
| `data/operators.json` | ชื่อแอป ลิงก์ Play Store/App Store/เว็บ ของผู้ให้บริการ |
| `data/osm-th.json` | snapshot สถานีจาก OpenStreetMap (ใช้เมื่อ Overpass ไม่ตอบ) |
