## ทำไมเรียงแบบนี้

1. **Longdo ก่อน** เพราะแอปใช้ข้อมูลน้ำท่วมของเขาอยู่แล้วทุกวัน (ทั้งตอนวางแผนและการ์ด "ตรวจก่อนออกเดินทาง") โดยยังไม่ได้ขออนุญาต ถ้าเขาไม่อนุญาต ปิดได้ทันทีที่หลังบ้าน → สถานะระบบ → "เลี่ยงถนนน้ำท่วม (Longdo Traffic) · สวิตช์หลัก" กด "ปิด"
2. **OR** ขอข้อมูลเพื่อให้แอปแนะนำสถานี PluZ ได้ครบ ไม่เร่งเท่า Longdo แต่ยิ่งได้เร็ว แผนการเดินทางยิ่งแม่น
3. **พันธมิตร** ส่งได้เรื่อย ๆ เริ่มจากกลุ่ม A ช่วงปากช่องใน `docs/route2-places.md` · **ถ้าขับทดสอบกรุงเทพฯ → ขอนแก่น แวะคุยระหว่างทางได้เลย**

## ไม่ต้องส่งจดหมาย

- **เซ็นเซอร์น้ำบนถนน กทม. (POPNIX Flood / สำนักการระบายน้ำ):** ใช้ได้ตามเงื่อนไข Open API โดยให้เครดิต ซึ่งมีใน footer ของแอปแล้ว

## หลังส่ง

- จดวันที่ส่งและช่องทางไว้ ถ้าเงียบ 2 สัปดาห์ ติดตามอีกครั้งแบบสุภาพทางช่องทางเดิม
