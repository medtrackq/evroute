# EVROUTE · ชุดโพสต์การตลาด

## คำขวัญ (สโลแกน)

**ไม่ต้องกลัวไฟหมด ไม่อดตาย มี EVROUTE เป็นเพื่อนร่วมทาง**
(คิดโดยเจ้าของโปรเจกต์ 24 ต.ค. 2569)

- "ไม่ต้องกลัวไฟหมด" = วางแผนจุดชาร์จให้ตลอดทาง
- "ไม่อดตาย" = ฟีเจอร์ "อยากแวะ" เลือกจุดชาร์จที่มีข้าว กาแฟ ห้องน้ำ ตรงช่วงมื้ออาหาร
- "เพื่อนร่วมทาง" = น้ำเสียงของแอป เป็นกันเอง อยู่ข้าง ๆ ตลอดการเดินทาง

แบบสั้นสำหรับคลิป/แบนเนอร์:
- ไฟไม่หมด ท้องไม่หิว · EVROUTE เพื่อนร่วมทางสาย EV
- ชาร์จตรงไหน กินอะไร ถึงกี่โมง · EVROUTE บอกครบ
