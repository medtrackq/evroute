# EVROUTE · ชุดโพสต์การตลาด

## คำขวัญ (สโลแกน)

**ไม่ต้องกลัวไฟหมด ไม่อดตาย มี EVROUTE เป็นเพื่อนร่วมทาง**
(คิดโดยเจ้าของโปรเจกต์ 24 ต.ค. 2569)

- "ไม่ต้องกลัวไฟหมด" = วางแผนจุดชาร์จให้ตลอดทาง
- "ไม่อดตาย" = ฟีเจอร์ "อยากแวะ" เลือกจุดชาร์จที่มีข้าว กาแฟ ห้องน้ำ ตรงช่วงมื้ออาหาร
- "เพื่อนร่วมทาง" = น้ำเสียงของแอป เป็นกันเอง อยู่ข้าง ๆ ตลอดการเดินทาง

แบบสั้นสำหรับคลิป/แบนเนอร์:
- ไฟไม่หมด ท้องไม่หิว · EVROUTE เพื่อนร่วมทางสาย EV
- ชาร์จตรงไหน กินอะไร ถึงกี่โมง · EVROUTE บอกครบ
- หน้าฝน: ไฟไม่หมด ท้องไม่หิว ไม่ต้องลุยน้ำ · EVROUTE พาเลี่ยงถนนน้ำท่วมให้

## ชุดหน้าฝน · "เลี่ยงถนนน้ำท่วมให้อัตโนมัติ" 🌊

จุดขายที่แอปวางแผนชาร์จเจ้าอื่นยังไม่มี: วางแผนชาร์จ **บนเส้นทางที่เลี่ยงถนนน้ำท่วมแล้ว** ใช้ข้อมูลรายงานของกรมทางหลวงและผู้ใช้ Longdo Traffic รวมถึงเซ็นเซอร์น้ำบนถนน กทม. อัปเดตทุก 2 นาที

### กติกาเฉพาะชุดนี้ (สำคัญกว่ากติกาทั่วไป)

1. **ส่งจดหมายถึง Longdo ก่อน** (`docs/letter-Longdo.md`) โพสต์ชุดนี้แบบโฆษณาได้เมื่อ Longdo ตอบอนุญาตแล้ว ระหว่างรอ ใช้ได้แค่ตอบคำถามในกลุ่มแบบไม่โฆษณา
2. **ใส่เครดิตทุกโพสต์:** "ข้อมูลน้ำท่วม: กรมทางหลวง / Longdo Traffic" (หรือตามรูปแบบที่ Longdo กำหนด)
3. **ห้ามพูดว่า "ปลอดภัย 100%" หรือ "ไม่มีวันเจอน้ำท่วม"** ใส่ประโยคนี้ทุกครั้ง: "แอปเลี่ยงได้เฉพาะจุดที่มีรายงาน ถนนที่ไม่มีรายงานไม่ได้แปลว่าแห้ง ตรวจสอบก่อนออกเดินทาง สายด่วนกรมทางหลวง 1586"
4. **อย่าทำการตลาดบนความเดือดร้อน:** ช่วงน้ำท่วมหนักที่มีผู้เดือดร้อนมาก ให้โพสต์แบบ "ข้อมูลบริการ" สั้น ๆ ไม่ใช้อีโมจิสนุก ๆ ไม่เล่นมุก ไม่ใส่ภาพบ้านเรือนของผู้ประสบภัย
5. **โพสต์เฉพาะตอนมีจุดน้ำท่วมจริง:** ดูบรรทัด "วันนี้มีถนนน้ำท่วมที่ผ่านไม่ได้ N จุด" ใต้สวิตช์ 🌊 ในฟอร์มวางแผน ถ้าไม่มี ให้ใช้โพสต์แบบ "รู้ไว้ก่อนหน้าฝน" แทน
6. **ตัวอย่างในโพสต์ต้องเป็นของจริงวันนั้น:** เปิดแอป วางแผนทริปที่ผ่านจุดน้ำท่วม แคปหน้าจอและอัดคลิปวันเดียวกับที่โพสต์ แล้วใส่วันที่ไว้ในโพสต์ (จุดน้ำท่วมเปลี่ยนทุกวัน)
7. ลิงก์ใช้ `?ref=flood-facebook` / `?ref=flood-tiktok` / `?ref=flood-group` จะได้รู้ในหลังบ้านว่าชุดนี้ดึงคนได้แค่ไหน
8. แฮชแท็กเพิ่ม: `#ถนนน้ำท่วม #เช็กน้ำท่วม #หน้าฝน #ขับรถหน้าฝน` + จังหวัดที่ท่วม

## 4. วัดผลทุกสัปดาห์ (หลังบ้าน)

- **คนเข้า / คนวางแผน / คนกลับมาใช้ซ้ำ** ภาพรวม
- **คนมาจากช่องทางไหน** แยกตามลิงก์ `ref` → หาร "เงินโฆษณาที่ใช้" = ค่าโฆษณาต่อคน
- **ปุ่มที่กด**: "เปิดแอปผู้ให้บริการ", "นำทางทั้งเส้น", "บันทึกแผน", "แผนที่พาเลี่ยงน้ำท่วม" = คนใช้จริง ไม่ใช่แค่เข้ามาดู
- **ข้อความจากผู้ใช้**: รุ่นรถที่ขอเพิ่ม, ปัญหาที่เจอ → แก้เร็ว แล้วโพสต์บอก "แก้ให้แล้วตามที่ขอ" (สร้างความเชื่อมั่นได้ดีมาก)

## 5. สิ่งที่ห้ามทำ

- ห้ามซื้อไลก์/ผู้ติดตาม/รีวิวปลอม และห้ามให้คนอื่นแกล้งเป็นลูกค้ามาชม
- ห้ามโพสต์ซ้ำ ๆ ในกลุ่มที่แอดมินไม่อนุญาต (โดนแบนทั้งเพจ)
- ห้ามอ้าง "สถานีครบทุกที่" หรือ "ปลอดภัย 100%" · ตัวเลขทุกตัวต้องมาจากแผนจริงในแอป พร้อมวันที่
- ห้ามใช้โลโก้/ชื่อ OR, PTT, PluZ, Longdo ในภาพโฆษณาแบบที่ดูเหมือนเขาร่วมทำ จนกว่าจะได้รับอนุญาต
