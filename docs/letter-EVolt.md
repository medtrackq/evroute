# ร่างจดหมายถึง EVolt (บริษัท อีโวลท์ เทคโนโลยี จำกัด)

> ร่าง 23 พ.ย. 2569 · แอปยังไม่เปิดให้คนทั่วไปใช้ จดหมายนี้จึงขออนุญาต**ก่อน**เปิดให้ใช้จริง ไม่มีตัวเลขผู้ใช้
> ใส่ชื่อ เบอร์โทร และอีเมลใน [วงเล็บเหลี่ยม] ก่อนส่ง

---

**เรื่อง** ขออนุญาตใช้ข้อมูลสถานีชาร์จ EVolt ในแอปวางแผนการเดินทาง EVROUTE

**เรียน** ผู้บริหาร บริษัท อีโวลท์ เทคโนโลยี จำกัด

ข้าพเจ้า [ชื่อ-นามสกุล] ผู้พัฒนา **EVROUTE** (https://evroute.info) เว็บแอปวางแผนการเดินทางสำหรับผู้ใช้รถยนต์ไฟฟ้าในประเทศไทย ใช้งานฟรี ไม่ต้องสมัครสมาชิก รองรับภาษาไทย อังกฤษ และจีน ขณะนี้ **อยู่ระหว่างทดสอบ ยังไม่เปิดให้ประชาชนทั่วไปใช้** ข้าพเจ้าจึงขอเรียนมาเพื่อขออนุญาตใช้ข้อมูลสถานีของ EVolt **ก่อน**เปิดให้ใช้จริง

**EVROUTE ทำอะไร**
ผู้ใช้เลือกรุ่นรถ ระดับแบตเตอรี่ ต้นทางและปลายทาง ระบบจะคำนวณว่าควรแวะชาร์จที่สถานีใด ชาร์จนานเท่าไร และค่าไฟประมาณเท่าใด เลือกสถานีที่อยู่ฝั่งขาไปเพื่อไม่ต้องกลับรถ เลือกจุดแวะที่มีร้านอาหารและห้องน้ำ และก่อนวันเดินทางจะตรวจทริปซ้ำว่าสถานีที่จะแวะมีผู้ใช้แจ้งปัญหาหรือไม่ เมื่อถึงจุดแวะ ผู้ใช้กดปุ่ม **"เปิดแอป EVolt"** เพื่อชาร์จและชำระเงินในแอปของท่านได้ทันที

**ข้อมูลของ EVolt ที่ใช้อยู่ระหว่างทดสอบ**
- รายชื่อสถานีชาร์จแบบ DC **54 สถานี** จากหน้า "สำหรับผู้ขับขี่" บนเว็บไซต์ evolt.co.th ได้แก่ ชื่อสถานี ที่อยู่ พิกัด และชนิดหัวชาร์จ (CCS2 / CHAdeMO)
- หน้าดังกล่าวไม่ได้ระบุกำลังไฟ แอปจึงคำนวณเวลาชาร์จโดยถือว่าเป็น 50 kW ทุกสถานี ซึ่งอาจไม่ตรงกับความจริง
- ค่าบริการใช้ค่ากลางจากข้อมูลที่เผยแพร่ (DC ราว 8–10 บาทต่อหน่วยตามสถานี)
- ระบุแหล่งที่มา "สถานีชาร์จ: EVolt" ในหน้าเว็บ

เนื่องจากไม่พบเงื่อนไขการนำข้อมูลไปใช้บนเว็บไซต์ ข้าพเจ้าจึงขออนุญาตอย่างเป็นทางการ **หากท่านไม่สะดวกให้ใช้ ข้าพเจ้าจะนำข้อมูลของ EVolt ออกจากแอปก่อนเปิดให้ใช้จริง**

**สิ่งที่ขออนุญาตและขอความร่วมมือ** (เรียงตามความสำคัญ)
1. **อนุญาตให้ EVROUTE ใช้รายชื่อสถานี EVolt** เพื่อแสดงสถานีและวางแผนการเดินทาง พร้อมแจ้ง**รูปแบบการให้เครดิต**ที่ท่านต้องการ
2. **กำลังไฟ (kW) ของแต่ละสถานี** และรายชื่อสถานีฉบับล่าสุด (รวมสถานีที่เปิดใหม่) จะเป็นไฟล์ที่อัปเดตเป็นระยะหรือ API ก็ได้ เพื่อให้คำนวณเวลาชาร์จได้ถูกต้อง
3. **อัตราค่าบริการของแต่ละสถานี** หรือหลักการคิดราคา เพื่อแสดงค่าชาร์จโดยประมาณให้ตรงกับความจริง
4. (ถ้าเป็นไปได้) **สถานะหัวชาร์จว่าง/ไม่ว่างแบบเรียลไทม์** และ**ลิงก์เปิดแอป EVolt ไปยังสถานีโดยตรง** (deep link)

**ประโยชน์ที่ EVolt จะได้รับ**
- **ผู้ใช้ถูกพาไปที่สถานี EVolt:** ระบบแนะนำจุดแวะจากระยะทาง แบตเตอรี่ และสิ่งอำนวยความสะดวกจริง สถานีที่มีข้อมูลกำลังไฟครบจะถูกเลือกได้แม่นยำขึ้น
- **ส่งผู้ใช้เข้าแอป EVolt โดยตรง:** การชาร์จและชำระเงินทั้งหมดยังเกิดในแอปของท่าน
- **ข้อมูลจากผู้ใช้ส่งกลับให้:** ผู้ใช้ EVROUTE แจ้งสถานีที่ชาร์จไม่ได้และบันทึกผลการชาร์จจริง เรายินดีสรุปส่งให้ทีมงานเป็นประจำ
- **ฟรี ไม่มีค่าใช้จ่าย:** เราไม่เก็บค่าบริการจากท่าน และหลังเปิดให้ใช้จริง ยินดีส่งสรุปจำนวนครั้งที่ผู้ใช้กดเปิดแอป EVolt ให้เป็นระยะ

**การใช้ข้อมูล**
ข้อมูลที่ได้รับจะใช้เพื่อแสดงสถานีและวางแผนการเดินทางใน EVROUTE เท่านั้น ไม่นำไปจำหน่ายหรือเผยแพร่ต่อ และยินดีลงนามข้อตกลงการใช้ข้อมูลตามที่ท่านกำหนด

ข้าพเจ้าหวังเป็นอย่างยิ่งว่าจะได้รับความร่วมมือจากท่าน และยินดีนัดหมายเพื่อสาธิตการใช้งานในวันและเวลาที่สะดวก

## ช่องทางส่ง

ยังไม่พบอีเมลบริษัทที่เผยแพร่ไว้ (อีเมลที่เจอเป็นของระบบสมัครงาน ไม่ควรใช้):
1. **LINE Official ของ EVolt** (ตรวจ LINE ID จากเว็บ evolt.co.th หรือในแอป EVolt) ส่งข้อความสั้น ขออีเมลผู้บริหารหรือฝ่ายพันธมิตร แล้วส่งจดหมายฉบับเต็มไปที่อีเมลนั้น
2. **ช่องทางติดต่อบนเว็บ evolt.co.th** หรือเบอร์โทรที่ระบุบนเว็บ
3. **สำนักงานใหญ่:** ซอยจุฬาลงกรณ์ 7 แขวงวังใหม่ เขตปทุมวัน กรุงเทพฯ (ตรวจที่อยู่เต็มจากเว็บก่อนส่งทางไปรษณีย์)

## เคล็ดลับ
- แนบภาพหน้าจอแผนการเดินทางที่มีจุดแวะ EVolt และปุ่ม "เปิดแอป EVolt"
- EVolt เป็นบริษัทเอกชนขนาดเล็กกว่า PEA และ OR มักตอบเร็วกว่าทาง LINE
- ถ้าเงียบ 2 สัปดาห์ ติดตามอีกครั้งแบบสุภาพทางช่องทางเดิม
