# ร่างจดหมายถึง Longdo Traffic (บริษัท เมตามีเดีย เทคโนโลยี จำกัด) และมูลนิธิ iTIC

> ใส่ข้อมูลใน [วงเล็บเหลี่ยม] ให้ครบก่อนส่ง · ตัวเลขผู้ใช้ดูได้จากหน้าหลังบ้าน (admin.html)
> ถ้าไม่ได้เปิดเว็บ roadflood ให้คนทั่วไปใช้ ให้ลบส่วนที่พูดถึง roadflood ออก

---

**เรื่อง** ขออนุญาตใช้ข้อมูลรายงานน้ำท่วมจาก Longdo Traffic ในแอปวางแผนการเดินทาง EVROUTE

**เรียน** ทีมงาน Longdo Traffic บริษัท เมตามีเดีย เทคโนโลยี จำกัด
**สำเนาเรียน** มูลนิธิศูนย์ข้อมูลจราจรอัจฉริยะไทย (iTIC)

ข้าพเจ้า [ชื่อ-นามสกุล] ผู้พัฒนา **EVROUTE** (https://evroute.onrender.com) เว็บแอปวางแผนการเดินทางสำหรับผู้ใช้รถยนต์ไฟฟ้าในประเทศไทย ใช้งานฟรี ไม่ต้องสมัครสมาชิก รองรับภาษาไทย อังกฤษ และจีน ขอขอบคุณ Longdo Traffic และมูลนิธิ iTIC ที่เผยแพร่ข้อมูลเหตุการณ์บนถนนให้ประชาชนใช้มาอย่างต่อเนื่อง

**EVROUTE ทำอะไร**
ผู้ใช้เลือกรุ่นรถ ระดับแบตเตอรี่ ต้นทางและปลายทาง ระบบจะคำนวณเส้นทาง จุดแวะชาร์จ เวลาที่ใช้ และค่าไฟโดยประมาณ

**ใช้ข้อมูลของ Longdo Traffic อย่างไร**
ช่วงหน้าฝนนี้ เราเพิ่มฟังก์ชัน **"เลี่ยงถนนน้ำท่วม"** เพราะรถยนต์ไฟฟ้ามีแบตเตอรี่อยู่ใต้ท้องรถ ผู้ขับจึงกังวลเรื่องการขับผ่านน้ำท่วมเป็นพิเศษ ระบบทำงานดังนี้
- server ของเราอ่าน feed เหตุการณ์ของ Longdo Traffic (`event.longdo.com/feed/json`) **ครั้งเดียวทุก 2 นาที** แล้วเก็บไว้ (cache) ส่งต่อให้ผู้ใช้ทุกคน เบราว์เซอร์ของผู้ใช้ไม่ได้เรียก Longdo โดยตรง
- ใช้**เฉพาะเหตุการณ์น้ำท่วม** ได้แก่ ตำแหน่ง ชื่อเหตุการณ์ สถานะ (ผ่านได้ / ผ่านไม่ได้) และเวลา
- ถ้าเส้นทางของผู้ใช้ผ่านจุดที่ผ่านไม่ได้ ระบบจะหาเส้นทางเลี่ยงให้ และแสดงรายการจุดน้ำท่วมบนเส้นทาง พร้อมระบุแหล่งที่มา (กรมทางหลวง / ผู้ใช้ Longdo Traffic) และเวลาที่ยืนยันล่าสุด
- ระบุเครดิต "ถนนน้ำท่วม: Longdo Traffic (iTIC)" พร้อมลิงก์ไปที่ traffic.longdo.com ในหน้าเว็บ
- ไม่ขายและไม่เผยแพร่ข้อมูลดิบต่อ ไม่เก็บข้อมูลย้อนหลัง

ข้าพเจ้าขอเรียนตามตรงว่า ขณะนี้ฟังก์ชันนี้เปิดให้ใช้แบบทดลองแล้ว และเว็บ **เช็กถนนน้ำท่วม (roadflood)** [ลิงก์] ของข้าพเจ้าก็ใช้ข้อมูลชุดเดียวกัน เนื่องจากยังไม่พบเงื่อนไขการใช้ feed นี้ที่เผยแพร่ไว้ จึงเขียนมาเพื่อขออนุญาตอย่างเป็นทางการ **หากทาง Longdo ไม่สะดวกให้ใช้ ข้าพเจ้าจะหยุดใช้ข้อมูลทันที**

**สิ่งที่ขออนุญาตและขอคำแนะนำ**
1. **อนุญาตให้ EVROUTE และ roadflood ใช้ข้อมูลเหตุการณ์น้ำท่วม**จาก feed ข้างต้น โดยทั้งสองบริการให้ใช้ฟรี ปัจจุบันยังไม่มีรายได้
2. **รูปแบบการให้เครดิต**ที่ทาง Longdo และ iTIC ต้องการ (ข้อความ โลโก้ ลิงก์ ตำแหน่ง)
3. **เงื่อนไขการเรียกใช้** เช่น ความถี่ที่เหมาะสม หรือ API / key ที่ทาง Longdo ต้องการให้ใช้แทน ข้าพเจ้ายินดีเปลี่ยนตามทันที
4. หากในอนาคต EVROUTE มีรายได้ ข้าพเจ้ายินดีหารือเรื่องสัญญาอนุญาตใช้ข้อมูลเชิงพาณิชย์ตามที่ทาง Longdo กำหนด

**ประโยชน์ที่ Longdo Traffic และ iTIC จะได้รับ**
- **ความปลอดภัยของผู้ขับขี่:** รายงานของกรมทางหลวงและผู้ใช้ Longdo ถูกนำไปใช้ตอนวางแผนเดินทางจริง ช่วยให้ผู้ขับไม่ต้องขับเข้าไปเจอถนนที่ผ่านไม่ได้
- **ผู้ใช้รู้จัก Longdo Traffic มากขึ้น:** ทุกจุดน้ำท่วมระบุว่ามาจาก Longdo Traffic พร้อมลิงก์ไปที่เว็บของท่าน
- **รายงานจากผู้ใช้มากขึ้น:** เรายินดีเพิ่มปุ่ม "แจ้งน้ำท่วมใน Longdo Traffic" ให้ผู้ใช้ EVROUTE ส่งรายงานเข้าระบบของท่านโดยตรง
- **ส่งข้อสังเกตกลับให้:** เช่น จุดที่ผู้ใช้แจ้งว่าน้ำลดแล้วแต่ยังมีรายงานอยู่ เรายินดีสรุปส่งให้เป็นประจำ

## ช่องทางส่ง

1. **อีเมล info@mm.co.th** เป็นอีเมลที่หน้าเงื่อนไขการใช้ Longdo Map (map.longdo.com/terms) ให้ไว้สำหรับติดต่อเรื่องธุรกิจ ตั้งหัวเรื่องตามจดหมาย
2. **โทร บริษัท เมตามีเดีย เทคโนโลยี 02-108-1790-1** (เบอร์จากเอกสาร Longdo Map SDK) ขอสายทีม Longdo Traffic หรือถามว่าควรส่งเรื่องนี้ถึงใคร
3. **มูลนิธิ iTIC** (iticfoundation.org): ส่งสำเนาผ่านช่องทางติดต่อบนเว็บมูลนิธิ เพราะข้อมูลจราจรของ Longdo Traffic ส่วนหนึ่งมาจาก iTIC
