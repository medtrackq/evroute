# ร่างจดหมายถึง PEA VOLTA (การไฟฟ้าส่วนภูมิภาค)

> ร่าง 23 พ.ย. 2569 · แอปยังไม่เปิดให้คนทั่วไปใช้ จดหมายนี้จึงขออนุญาต**ก่อน**เปิดให้ใช้จริง ไม่มีตัวเลขผู้ใช้
> ใส่ชื่อ เบอร์โทร และอีเมลใน [วงเล็บเหลี่ยม] ก่อนส่ง

---

**เรื่อง** ขออนุญาตใช้ข้อมูลสถานีชาร์จ PEA VOLTA ในแอปวางแผนการเดินทาง EVROUTE

**เรียน** ผู้อำนวยการฝ่ายที่ดูแลธุรกิจสถานีอัดประจุไฟฟ้า PEA VOLTA
การไฟฟ้าส่วนภูมิภาค

ข้าพเจ้า [ชื่อ-นามสกุล] ผู้พัฒนา **EVROUTE** (https://evroute.info) เว็บแอปวางแผนการเดินทางสำหรับผู้ใช้รถยนต์ไฟฟ้าในประเทศไทย ใช้งานฟรี ไม่ต้องสมัครสมาชิก รองรับภาษาไทย อังกฤษ และจีน ขณะนี้ **อยู่ระหว่างทดสอบ ยังไม่เปิดให้ประชาชนทั่วไปใช้** ข้าพเจ้าจึงขอเรียนมาเพื่อขออนุญาตใช้ข้อมูลสถานีของ PEA VOLTA **ก่อน**เปิดให้ใช้จริง

**EVROUTE ทำอะไร**
ผู้ใช้เลือกรุ่นรถ ระดับแบตเตอรี่ ต้นทางและปลายทาง ระบบจะคำนวณว่าควรแวะชาร์จที่สถานีใด ชาร์จนานเท่าไร และค่าไฟประมาณเท่าใด เลือกสถานีที่อยู่ฝั่งขาไปเพื่อไม่ต้องกลับรถ เลือกจุดแวะที่มีร้านอาหารและห้องน้ำให้ตรงช่วงมื้ออาหาร และก่อนวันเดินทางจะตรวจทริปซ้ำว่าสถานีที่จะแวะมีผู้ใช้แจ้งปัญหาหรือไม่ เมื่อถึงจุดแวะ ผู้ใช้กดปุ่ม **"เปิดแอป PEA VOLTA"** เพื่อชาร์จและชำระเงินในแอปของ PEA ได้ทันที

**ข้อมูลของ PEA VOLTA ที่ใช้อยู่ระหว่างทดสอบ**
- รายชื่อสถานีชาร์จแบบ DC **407 สถานี** จากแผนที่สถานีบน Google My Maps ที่ลิงก์จากหน้าสถานีชาร์จบนเว็บไซต์ PEA VOLTA ได้แก่ ชื่อสถานี ที่อยู่ เวลาเปิด-ปิด พิกัด และกำลังไฟ (kW)
- แผนที่ดังกล่าวไม่ได้ระบุชนิดหัวชาร์จ แอปจึงแสดงว่า "ยังไม่ยืนยันชนิดหัวชาร์จ" ทุกสถานี
- อัตราค่าบริการที่ PEA ประกาศ (DC 50–180 kW: On-Peak 6.90 / Off-Peak 5.90 บาทต่อหน่วย ตั้งแต่ 1 พ.ค. 2569) ใช้คำนวณค่าชาร์จโดยประมาณ
- ระบุแหล่งที่มา "สถานีชาร์จ: PEA VOLTA (การไฟฟ้าส่วนภูมิภาค)" ในหน้าเว็บ

เนื่องจากเว็บไซต์ของ PEA VOLTA ระบุลิขสิทธิ์ไว้ และไม่พบเงื่อนไขการนำข้อมูลไปใช้ ข้าพเจ้าจึงขออนุญาตอย่างเป็นทางการ **หาก PEA ไม่สะดวกให้ใช้ ข้าพเจ้าจะนำข้อมูลของ PEA VOLTA ออกจากแอปก่อนเปิดให้ใช้จริง**

**สิ่งที่ขออนุญาตและขอความร่วมมือ** (เรียงตามความสำคัญ)
1. **อนุญาตให้ EVROUTE ใช้รายชื่อสถานี PEA VOLTA** เพื่อแสดงสถานีและวางแผนการเดินทาง พร้อมแจ้ง**รูปแบบการให้เครดิต**ที่ PEA ต้องการ (ข้อความ โลโก้ ลิงก์)
2. **รายชื่อสถานีฉบับล่าสุดจาก PEA โดยตรง** ที่มี**ชนิดหัวชาร์จ** (CCS2 / CHAdeMO / AC Type 2) และจำนวนหัวในแต่ละสถานี จะเป็นไฟล์ที่อัปเดตเป็นระยะหรือ API ก็ได้ เพื่อให้ผู้ใช้ไม่ไปผิดสถานี
3. (ถ้าเป็นไปได้) **สถานะหัวชาร์จว่าง/ไม่ว่างแบบเรียลไทม์** และ**ลิงก์เปิดแอป PEA VOLTA ไปยังสถานีโดยตรง** (deep link)
4. ยืนยัน**อัตราค่าบริการ**ปัจจุบัน และช่องทางที่ควรติดตามเมื่อมีการปรับราคา

**ประโยชน์ที่ PEA จะได้รับ**
- **ผู้ใช้ถูกพาไปที่สถานี PEA VOLTA บนเส้นทางหลักและเส้นทางต่างจังหวัด:** ระบบเลือกจุดแวะจากระยะทาง แบตเตอรี่ และสิ่งอำนวยความสะดวกจริง สถานีที่มีข้อมูลครบจะถูกแนะนำอย่างมั่นใจ
- **ส่งผู้ใช้เข้าแอป PEA VOLTA โดยตรง:** การชาร์จและชำระเงินทั้งหมดยังเกิดในแอปของ PEA
- **ข้อมูลจากผู้ใช้ส่งกลับให้ PEA:** ผู้ใช้ EVROUTE แจ้งสถานีที่ชาร์จไม่ได้ (เช่น หัวชาร์จเสีย ปิดปรับปรุง) และบันทึกผลการชาร์จจริง เรายินดีสรุปส่งให้ทีม PEA VOLTA เป็นประจำ
- **ฟรี ไม่มีค่าใช้จ่าย:** เราไม่เก็บค่าบริการจาก PEA และหลังเปิดให้ใช้จริง ยินดีส่งสรุปจำนวนผู้ใช้และจำนวนครั้งที่กดเปิดแอป PEA VOLTA ให้เป็นระยะ

**การใช้ข้อมูล**
ข้อมูลที่ได้รับจะใช้เพื่อแสดงสถานีและวางแผนการเดินทางใน EVROUTE เท่านั้น ไม่นำไปจำหน่ายหรือเผยแพร่ต่อ และยินดีลงนามข้อตกลงการใช้ข้อมูลตามที่ PEA กำหนด

ข้าพเจ้าหวังเป็นอย่างยิ่งว่าจะได้รับความอนุเคราะห์จากท่าน และยินดีนัดหมายเพื่อสาธิตการใช้งานในวันและเวลาที่สะดวก

## ช่องทางส่ง

ยังไม่พบอีเมลของทีม PEA VOLTA ที่เผยแพร่ไว้ ให้ถามช่องทางที่ถูกต้องก่อน แล้วส่งจดหมายฉบับเต็มทางอีเมลที่ได้:
1. **PEA Call Center 1129** ขอติดต่อหน่วยงานที่ดูแลธุรกิจสถานีชาร์จ PEA VOLTA เรื่อง "ขออนุญาตใช้ข้อมูลสถานีในแอปวางแผนการเดินทาง" แล้วขออีเมลผู้รับเรื่อง
2. **ช่องทางติดต่อบนเว็บ pea.co.th** (ติดต่อเรา) แนบจดหมายนี้
3. **เพจ Facebook PEA VOLTA** ส่งข้อความสั้น ขออีเมลหน่วยงานที่ดูแล
